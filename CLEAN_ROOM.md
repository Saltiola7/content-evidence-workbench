# Clean-room Declaration

Content Evidence Workbench is independently implemented in an empty-history
repository.

Forbidden inputs:

- employer or client code, prompts, schemas, data, screenshots, metrics,
  infrastructure, or Git history
- SaaS Pegasus, Flowbite Premium, or other restricted source and assets
- personal information, credentials, and private machine paths

Allowed inputs:

- general retrieval, citation, entity, graph, evaluation, and HITL concepts
- public standards and documented open-source APIs
- independently authored code
- deterministic synthetic or explicitly redistributable fixtures

Every reference run records model, parameters, fixture identity, generation
date, citations, and human edits. Reference output never implies live provider
execution.
