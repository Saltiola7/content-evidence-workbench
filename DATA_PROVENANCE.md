# Data Provenance

The default corpus is generated by repository code from fictional organizations,
products, policies, and documents. It contains no employer or client content.

Every committed data artifact records:

- generator or source version
- license and owner
- schema and row grain
- generation date and seed
- transformations and content hash
- privacy and redistribution decision

Uploaded visitor files remain runtime-only and are never committed, logged,
snapshotted, or sent to a model provider unless the visitor explicitly enables
a disclosed BYOK call.
